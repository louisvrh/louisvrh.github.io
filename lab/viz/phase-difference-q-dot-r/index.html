Why the phase difference between two atoms is q·R

  1. Start equal. Both incoming rays start in phase on wavefront A (a line ⟂ kin).
  2. Extra path in, d = k̂in·R: the ray to R has to travel this far past the dashed line through O. That is the projection of R onto the incoming direction.
  3. Extra path out, d′ = k̂out·R: on the way out it is the ray from O that is longer, by the projection of R onto the outgoing direction. Both rays end on wavefront B (⟂ kout, towards the far-away detector).
  4. Net. The R-ray travels d − d′ further. Multiply by 2π/λ = |k|: phase difference = kin·R − kout·R = −(kout − kin)·R = −q·R.

Bottom: q = kout − kin is the vector you must add to kin to get kout. Because |kin| = |kout| (elastic), the triangle is isosceles. If q·R is a multiple of 2π for every atom R, all the rays arrive in step and you get a bright beam: that is q = G.
