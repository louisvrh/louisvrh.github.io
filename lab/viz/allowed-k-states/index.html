Why these k, and why it matters

Only some k fit the ringClosing the chain forces un+N = un, so eikNa = 1 and kL = 2πp: an integer number p of wavelengths must fit around the ring. Drag k off a dot and the wave no longer joins at the seam.
Spacing 2π/L, but always N of themLonger chain: finer spacing 2π/L and density gk = L/2π. The zone has fixed width 2π/a, so the count is (2π/a)(L/2π) = N, one state per atom.
The continuum limitAs L → ∞ the dots fill the zone uniformly and Σk → (L/2π)∫dk (5.9). That is what turns thermodynamic sums over modes into integrals.
Travelling vs standing wavesRing: ±k are independent travelling waves, spacing 2π/L over (−π/a, π/a]. Box with fixed ends: standing waves sin(kna), k = pπ/L > 0, density L/π, same count.

What to notice

  • Press → ∞: the dots crowd together but never leave the zone, and their number stays N. The spacing 2π/L shrinks while the density L/2π grows.
  • Pick a dot: the sine wave around the ring closes exactly on itself, with p wavelengths. Drag between dots and a kink appears at the seam.
  • The Δk window always holds about (L/2π)Δk states, and (1/N)Σωk falls onto 4/π like 1/N² (ring).
Model and assumptions
  • Monatomic harmonic chain, nearest-neighbour springs, a = ωD = 1; ωD = √(κ/m) is the spring frequency, not a Debye cut-off.
  • Ring: un+N = un. Allowed p follow Eq. 5.2 exactly: p = 0, ±1, …, ±(N−1)/2 for odd N; p = −N/2+1, …, N/2 for even N (the zone-edge state k = π/a exists only for even N).
  • Box: fixed ends u0 = uN = 0 give N−1 modes sin(pπn/N), p = 1, …, N−1 (one per mobile atom), spacing π/L, density L/π; so the count is N−1, which is N in the large-N limit.
  • Each displayed mode is an exact analytic solution, un = A cos(kna − ωkt) (ring) or A sin(kna) cos ωkt (box). No time-stepping is used on the page; the test suite also checked them against velocity-Verlet evolution of the ring (energy drift < 1e-5 over 25 periods).
  • The k = 0 mode is a uniform shift with ω = 0 (no restoring force); the page shows it as a static offset. The thermal mixture is a random-phase sum of all N−1 vibrational modes with amplitudes ∝ 1/ωk (equipartition-like), normalised to rms 0.25a.
  • The sum-vs-integral check uses the mean over allowed k of ωk (box: over its N−1 modes); the limit is 4/π in units of ωD.
