Tips for the problem sheet

  • Set the energy range so it covers only one band. The spectrum always has at least 1000 points, so a narrow range resolves every state in the band.
  • The list above shows the same numbers as E[peaks] in the notebook. Use Copy to paste them into Python.
  • For the sign of t, plot the amplitude of the lowest state in a band. Check whether neighbouring wells have the same sign or opposite signs.
Model and assumptions

The 1D Schrödinger equation is solved with 2×2 transfer matrices: an interface matrix ½[[1+c, 1−c],[1−c, 1+c]] with c = kn/kn+1 at each step, and diag(eikd, e−ikd) for propagation through each layer. It uses the free-electron mass (m = 9.11×10⁻³¹ kg), and the input and output leads at V = 0 are 5 nm long. The energy grid has max(⌊ΔE / 0.5 meV⌋, 1000) points. Points where |det T − 1| > 10⁻⁹ are dropped as rounding errors, as in the notebook. States are the local maxima of T(E), the same as scipy.signal.find_peaks with default settings. Checked against the notebook's own Python functions in six test cases (including N = 21 and N = 40): peak indices identical, T(E) agrees to 10⁻¹¹ relative, wavefunctions to 10⁻¹². The number of dropped points differs by a handful in the band gaps because of rounding.
